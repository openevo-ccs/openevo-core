OpenEvo Core

The shared kernel underneath every Foundational, Graph, and Project repo in the OpenEvo Computational Curriculum Studies Lab. Owns no curriculum content of its own.

GitHub Governance ConceptBase Research Lab

What is this?

This repo holds three things every other repo in the ecosystem depends on, but none of them owns: the oe: upper ontology, the OE-{TYPE}-###### identifier scheme, and the cross-repo RFC process for proposing a genuinely new shared ontology class. It also anchors the www.w3id.org/openevo/ namespace root.

It exists because that infrastructure used to live inside ConceptBase — the ecosystem's first mature repo — simply because ConceptBase was, for a time, the only real repo. It isn't anymore. Nine Foundational Repos now share this kernel co-equally.

This repo stores no entity instances — no Concepts, LPMs, Strands, Competencies, Resources, Projects, Literature records, People, Groups, Questions, Methods, or TheoryBase nodes. Every one of those lives in its own owning Foundational Repo, referenced by permanent identifier, never duplicated.
